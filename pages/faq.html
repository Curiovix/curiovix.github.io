Installing StorySplitz safely.

Because StorySplitz is a direct APK, Android will show a warning during installation. This is normal - here is what to do.

01

Download from official sources only

Only download the StorySplitz APK from this official Curiovix website or from official Curiovix GitHub Releases. Do not use third-party APK sites or file-sharing links.

02

Android will show a warning - this is normal

Android may show "For your security, your phone is not allowed to install unknown apps from this source." This is a standard Android security feature, not an indication the App is harmful.

03

Allow installation from your browser or file manager

Tap Settings when prompted, then enable "Allow from this source" for your browser or file manager only.

04

Complete the installation

Return to the APK and tap Install. StorySplitz is signed with an official Curiovix release certificate. If Play Protect flags it, tap Install anyway after verifying the download source.

05

Optionally disable the permission after installation

For extra security, disable "Allow from this source" in Settings after StorySplitz is installed.

06

Verify the version

Open StorySplitz, check the app version in Settings, and compare it with the version listed on this website.

Important: Never download from unofficial APK sites. Android's warning is protective - only proceed if you downloaded from an official Curiovix source. Do not disable Android security protections globally.
